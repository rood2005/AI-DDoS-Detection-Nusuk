# AI-Enhanced Defence Mechanisms for Mitigating Cyber Attacks on Pilgrimage Applications

## Overview
This repository contains the simulation code, evaluation scripts, and Jupyter notebooks for detecting DoS and DDoS attacks targeting pilgrimage web and mobile services (Case Study: Nusuk).

## Implemented Models & Scripts
* `Randomforest_100runs.py` / `Random_Forest_—_UNSW_NB15.ipynb`: Random Forest Classifier with hyperparameter tuning across datasets.
* `Logistic Regression.py` / `LogisticRegression_UNSW_.ipynb`: Logistic Regression baseline models.
* `Svm_100.py` / `SVM_UNSW_.ipynb`: Support Vector Machine implementations.
* `lstm_ddos.py` / `LSTM.ipynb`: Long Short-Term Memory (LSTM) deep learning approaches.

## Key Datasets
* **CICDDoS2019** (Primary DDoS evaluation dataset)
* **UNSW-NB15** (Cross-dataset evaluation & generalization testing)
